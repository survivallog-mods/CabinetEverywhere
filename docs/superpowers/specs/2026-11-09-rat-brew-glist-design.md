## 1. 意图与动机

老鼠笼、酿酒桶两页找料费眼：喂鼠要看饱腹、酿酒要看品质，旧版简化侧栏（官方格网+页脚排序钮）翻柜找食
效率低。本批把 v1.9.0 全局物品栏（glist）扩装到这两页——跨「背包+整屋柜子」全局搜索、同名汇总一行、
右键直达目标仓，进页自带预设：**两页都按饱腹度降序**；酿酒桶行角标用**游戏本体三档酒精瓶图标+品质色**
把「这件原料酿出什么」一眼标出来。

**作者裁定（2026-11-09 对谈，逐条已对齐）**：
1. 筛选：老鼠笼=所有带饱腹数值的食物；酿酒桶=所有可酿酒的食物；隐藏物页脚计数（染料/暖炉同款）。
2. 右键目标：老鼠笼→食物仓、酿酒桶→酿酒桶（官方移动口径，路径实现期探明）。
3. 角标：老鼠笼=🍗饱腹数值（绿）；酿酒桶=饱腹数值+品质颜色区分（**非文字**，图标=游戏酒精瓶实物图）。
4. 两页旧版简化侧栏**整体退役**（含酿酒桶 v14.1 排序钮收敛/品质文字角标/置灰——cfg 关=原路回归）。
5. （builder check 轮）**同名异值拆行**：同名物品饱腹数值不同的不合并、各行分开（实据=蒜蓉西兰花双版本
   40/20 系全游戏唯一老鼠笼页碰撞组；可酿物品零碰撞）。
6. （builder check 轮）**格子态页脚保留**：照染料页留格数+📦一键入库+一键整理（暖炉/发电机「全拆」先例
   不采）。
7. （收口轮）**零配置开关**：两页 glist 随 mod 安装即启用，**不新增** `EnableGlistRat`/`EnableGlistBrew`
   键（作者令「安装了 mod 就默认启用」）。
8. （v2.2.3 追批）**左键=官方原生详情弹窗（全部行）**：作者实报 mod 自建详情弹窗属性不全（食物只显
   饱腹一维，缺生命/精力/心态），令「列表里**所有**物品都用官方原生详情弹窗」——FEFO 挑中那叠 →
   C# 直调 `Ac_ItemDetailPopup_OpenUI`（ItemId+OwnerId 实例级：官方动作自带 OwnerId=柜源行同样
   可开，**无 bag 源限制**；TipsType=Default 纯查看；gamekb dump @130893 定谳，TradeFx OpDetail
   先例同款）。mod 自建 srgDetail 六页统一退役。六场景统一生效（非仅 rat/brew）。

## 2. 目标 / 非目标 / 反目标

**目标**
- GLIST 描述符扩两页：`RatCage:{target:'食物仓',badge:'sat'}`、`BrewPanel:{target:'酿酒桶',badge:'brew'}`
  （六段面板/装配链 glistFrame 全套复用，零新壳）。
- 预设：无 chips（两页无可选维度），仅常驻排序牌「🍗 按饱腹度 ↓」；排序=纯饱腹数值（s1）降序、
  并列稳定，**品质不参与排序**（作者令）。
- 行角标：老鼠笼 🍗+数值，固定绿 #8fc06e（FBCOLOR.sat 全 mod 惯例）；酿酒桶=**游戏三档酒精瓶 WebIcon
  实物图**（15505 劣质青绿液/15504 普通橙黄液/15506 烈性红液，随档换瓶）+ 数值，描边/文字叠同档色
  （劣 #7fe05a / 普 #ffc93c / 烈 #ff7086——色相照官方品质条与瓶液，饱和度调高一档，作者验收稿）。
- 隐藏：老鼠笼藏「无饱腹数值」（s1≤0）物品、酿酒桶藏「不可酿」（bw=0）物品；页脚右下计数
  「已按预设隐藏 N 种无饱腹物品/不可酿物品」；**不可取消、无「显示全部」开关**（暖炉 lock 同哲学）。
- 右键=官方口径移 1 件（食物仓/酿酒桶），FEFO 取最快过期叠、toast 报来源；悬停信息条/左键详情与
  染料页同款三键（品质文字只出现在悬停/详情，角标上禁文字）。
- 列表↔格子互切：格子态=**rail 简洁态**（染料页同机制：官方背包格原样+**页脚保留**格数/📦一键入库/
  一键整理——裁定#6；排序钮/品质角标不在格子态出现）；视图记忆 localStorage 同键规。
- 两页旧简化侧栏随 glist 在场退役，**退役范围=排序钮（srFoodSort）+v14.1 品质角标/置灰**；页脚三件
  （格数/入库/整理）保留（裁定#6）；旧侧栏代码路径保留但两页常抑制（**无 cfg 回退**——回退=装回旧版 DLL）。
- 配置：**零新增配置键**——两页 glist 随 mod 安装即启用（裁定#7）；ctx.glistOn 两页恒真（无条件装配）。
  既有 `EnableRatCage`/`EnableBrew` 键对这两页失去作用对象（键保留兼容防配置文件报缺，不再 gating，
  配置界面文案随批更新）。

**非目标（本次不做）**
- chips 筛选标签、品质参与排序、角标品质文字（作者已否）。
- 其他任何页面的菜单/排序/角标/推送形状变化（icfg `bw` 尾列仍只允许 BrewPanel 页出现——v14.1 约束照旧；
  RatCage 页零尾列零新字段）。
- 官方右半页面（老鼠笼笼体/酿酒桶发酵面板、品质条、料仓）任何改动。

**反目标（做了即失败）**
- 动官方格 DOM/监听（§0 红线）；数据层副作用（右键=官方口径事件回放，非自造转移）。
- 从 Category==食物 推导筛选判据（Burnable/CanBrew 同纪律：老鼠笼=s1 实值、酿酒桶=物品级 bw 标志）。
- 公共聚合/比较器加页专属分支（v14.1 拆专属 apply 同纪律：预设走 GLIST 场景描述符数据，不动公共件）。

## 3. 约束与现成件（实现者的既有事实）

- **数据全现成，仅差一个图标字段**：
  - s1/s2=饱腹/心态，items 行自带（契约 v4，RailSortMath 实例+天赋口径，`RailData.cs:21-23/551-555`）；
  - icfg `bw`（CanBrew）尾列=BrewPanel 页专属已实装（v14.1，`normIcfg r[15]`）；ctx `brewP1/brewP2`
    同页已推（BrewPanel 页）；tier 计算=v14.1 `brewTierOf`（s2/s1 三档，null→-1）现成逻辑；
  - **新增仅一处**：ctx 页条件字段 `brewIco:[劣,普,烈]`（BrewPanel 页）——C# 读 Config_Item 15505/15504/15506
    的 WebIcon（dyePal 页条件先例同点位；三 URL 顺序=TIERS 档序，缺省容错为空数组→角标退纯色不含图）。
- GLIST 描述符/装配链/FEFO/GLPEND 双跳/视图记忆/签名守卫：UI-SPEC §0b-glist 全套。聚合键=v2 终案
  （名+uses+attrSig）**本批两页追加角标数值维度**：rat 键+`s1`、brew 键+`s1+s2`（tier=s2/s1 派生，双值
  齐拆才不虚标档）——同名异值即拆行（裁定#5）；染料/暖炉两页维持首件代表现状不动（非本批范围）。
- 键盘门：`GlistKeyboardTick` 扩 RatCage/BrewPanel 两页（IME 搜索，0.3s 节流，对称还原）。
- 版式：面板宽 616（spec §5 定稿）；高随宿主（两页宿主锁=实现期 spike S3，heater 778/dye 816 先例）。

## 4. 方案选型

| 决策点 | 选定 | 被否选项（否决原因） |
|---|---|---|
| 扩页方式 | **GLIST 描述符+场景预设数据**（批改#8 发电机复用同模式） | 每页自建面板（三页已共用一套壳，重复六段结构）；旧侧栏共存可切换（作者令退役，双背包区混乱） |
| 角标图标 | **游戏三档酒精瓶 WebIcon 随档换瓶** | emoji 酒类（🍷/🍶/🍾/🥃——作者两轮否决：「用游戏中的酒精瓶那个样式」）；鸡腿+色点（数字绿+小点，首问被否，改整标换色） |
| 品质呈现 | 图标（瓶液颜色=游戏画好的档位语义）+描边文字叠色，双通道 | 品质文字（作者令「不是文字」）；纯色点（不显眼） |
| 品质三色 | 官方品质条色相、饱和度调高一档（#7fe05a/#ffc93c/#ff7086） | 官方原色直用（#9dc47f/#e8b04b/#e0899b——作者令「颜色区分稍微明显一点」；官方品质条本体仍原色不动） |
| 排序键 | 纯 s1 降序 | 品质主键+s1 次键（v14.1 旧径——作者令品质只管显示不管顺序） |
| 老鼠笼筛选 | s1>0 实值判据 | Category==食物推导（物品级纪律） |
| 同名异值并行 | **拆行**（角标数值维度进合并键：rat+s1、brew+s1+s2） | 首件代表（染料现行——蒜蓉西兰花 5 组会虚标）；角标跟随 FEFO 取件（取一件跳一档，观感不稳） |
| 格子态页脚 | **保留**（染料先例：格数/入库/整理） | 全拆（暖炉/发电机先例——作者选染料式） |

## 5. 实现设计（4 文件，全部页门控）

### 5.1 C# `RailData.cs`
- ctx 增补（dyePal 先例同点位，仅 BrewPanel 页）：`"brewIco":F(WebIcon[15505])+","+F(WebIcon[15504])+","+
  F(WebIcon[15506])`（或 JSON 小数组；try/catch 缺省空）。物品 ID 不硬编码以外的口径——照 dyePal
  「读不到就空」容错，窗口期角标无图不崩。
- **不新增配置键**：两页 glist 无条件装配（裁定#7）；`ctx.glistOn` 两页恒真，`EnableRatCage`/`EnableBrew`
  不再作用于这两页（键保留兼容）。

### 5.2 JS `railui.page.js`
- `GLIST` 扩两页描述符；badge 渲染分流：`sat`=🍗+s1 绿；`brew`=瓶图（ctx.brewIco[tier]）+s1+档色壳
  （tier=brewTierOf 复用；bw=0 的行不存在——已被预设隐藏）。
- `glistAggregate` 场景排序：sat 键=s1 降序+并列稳定+沉底不适用（无值行已被过滤）；预设过滤：
  rat=行 s1>0、brew=ICFG bw=1；隐藏计数进页脚右下。
- 排序牌常驻「🍗 按饱腹度 ↓」（两页同文案）；chips 行空。
- 右键 feed：走各页官方路径（S1/S2 spike 结论接线；bag 源直回放、柜源 take+GLPEND 双跳照 dye 模式，
  或 OpFeed 式两态机照 heater——按探明的官方动作定）。
- plain 侧栏抑制门扩两页（`glistOwnsPage` 口径：glist 在场即抑制 ensurePlain/排序钮装配）；
  格子态=官方默认背包（refreshBag 裸命令→RefreshActivePage 已三页全覆盖，`Ac_RatCage_RefreshBag`
  已存在 `RailData.cs:134`；BrewPanel 同款确认）。

### 5.3 CSS `railui.css`
- `.vbico`（13px 瓶图、drop-shadow）+brew 档色壳类；页脚隐藏计数复用现有样式。

### 5.4 原型 `design-proto/`（可选）
