# 染料桶色素排序（Dye Pigment Sort）设计文档

- 日期：2026-11-07
- 状态：待作者批准
- 前史：v1.8.10 十三批作者令 `−DyePanel（先撤钮，颜料桶排序待重设计）`——本文档即该重设计。
- 数据分析诉求（同场提出）：全植物×全颜色色素数值表，随本功能 spike 一并产出（附录 A）。

## 1. 意图与动机

染料桶界面找原料费眼：背包/柜子里植物混在杂物中，官方只对"含当前颜色的植物"描边+右下角水滴点数（仅已解锁色、仅当前色）。玩家想按某个颜色快速把"能给这个颜色多少点"的植物排出来——包括还没解锁的颜色（提前规划种什么/囤什么）。

做法：回归 mod 惯用的**显示层排序 DISP**（v1.8.5 ProjectCook 机制：纯模型 x/y 写+官方自渲染，真实摆放零触碰），排序维度=颜色（全部颜色，含未解锁）。关面板即还原，不动存档、不动真实背包布局。

## 2. 目标 / 非目标 / 反目标

**目标**
- 染料桶页脚最左位回归排序钮（与一键整理同排、左对齐——v1.8.6 定下的位置惯例）
- 排序弹窗列出**全部颜色**（含未解锁），选色即按该色色素点数降序排官方格
- 无该色素/非植物沉底且保持原相对顺序；并列稳定
- 所排颜色的点数以角标显示（与其他排序维度同款右上角数值角标）
- 产出全植物×全颜色色素数值表（附录 A，对账+wiki 可搬）
- harness 回归：排序应用/数据推送重应用/官方序还原/多格物品装填

**非目标**
- 不物理移动物品、不改真实背包布局（v1.8.5 起数据层排序已全线退役，不复活）
- 不与「提取颜色」下拉联动（选色即排一次，独立状态）
- 不做置灰（官方描边已聚焦当前色；沉底本身达成"无色素靠后"）
- 不动原料槽（vatGrid）——它是指配方槽不是容器

**反目标**
- 排序后拖拽错位/坐标穿帮（必须走 DISP 既有拖拽同步与 dropFilter 体系）
- 数据层副作用：任何 ItemManager 移动类调用（本功能零命令下发）
- 公共比较器再长页专属分支（v14.1 当天先例：酿酒桶已拆专属 apply，染料同构）

## 3. 约束

- 官方格渲染/拖拽零接管（mod 红线）；DISP 写模型 x/y 后由页面自渲染
- 契约行按页加尾列有先例：`icfg` FuelGenerator +[burnable,burnValue]、BrewPanel +[canBrew]（`RailData.cs:890` 起）；缓存分键防串形（`_icfgFuelCache` 先例，`RailData.cs:1217`）
- 色素数值源在 IL2CPP 配置侧（Web 端 `pigments` 字段只含已解锁色，且只随物品实例推送——不够全量排序用）
- 植物不堆叠（DyePanel 母本实证），点数=单件口径；但比较器/装填不做此假设（通用 w×h 走 dispPack）

## 4. 方案取舍

| 方案 | 概述 | 裁决 |
|---|---|---|
| A. 物理排序 | ITEM_MOVE 系列真实落位 | **弃**。官方 `SortContainerForHub` 规则写死塞不进色素比较器；逐件移动需自研打包+N 次命令+永久改玩家背包布局；与套件 v1.8.5"数据层排序退役"决策相逆 |
| B. 野路子拦截重写推送 | 挂官方数据推送链重写 x/y | **弃**。无契约、脆、与 v1.8.13 官方坐标自洽方向相逆 |
| **C. DISP 显示层排序（采用）** | 沿 v1.8.5 机制写 Vue 模型 x/y，官方自渲染；与全 mod 六个排序钮同构 | **采纳**。零副作用、拖拽体系现成、被撤的染料钮本来就是 DISP 系 |

C 内部一个子决策：**色素排序走专属 apply**（`dispApplyDyePig`，v14.1 酿酒桶 `dispApplyBrewSat` 同构），不在公共比较器加分支——作者 2026-11-07"不与公共排序规则混合"令的当日先例。

## 5. 设计

### 5.1 C#：契约扩展（RailData.cs）

1. **`icfg` 页专属尾列**：DyePanel 页行尾追加 `pig`——植物的全颜色点数打包串，如 `"[[3,2],[5,1]]"`=色号 3 给 2 点、色号 5 给 1 点；非植物/无色素=`"[]"`。照 fuelCols 先例：独立缓存 `_icfgDyeCache`（与 14 列/16 列缓存分键防串形）；读不到配置的字段时容错为空（与各行 try/catch 同口径）。
2. **页级字段 `dyePal`**：颜色板 `[[colorId,"名","#hex",unlocked,order],…]`（全量颜色；unlocked 读得到就带，读不到恒 1——见 spike S2）。仅 DyePanel 页下发。
3. **色素数值表 dump**：`Debug.DumpDyePigments`（默认 false，ListOnReady 同款节律）——日志打出全植物×全颜色点数表，验收对账后誊入附录 A。

### 5.2 JS：排序钮与弹窗（railui.page.js）

1. **DyePanel 回归排序页**：`SORT_KEYS` 重新纳入 DyePanel → 页脚 `srFoodSort`（RAIL_HTML 中本就排最左）不再 hidden。位置=与一键整理同排、靠左，与机器页页脚 `[排序钮][格数][入库|整理]` 布局一致。
2. **弹窗内容**：`默认`（official，复位）+ `dyePal` 全部颜色（色块 swatch + 色名；未解锁色正常可选）。BrewPanel 定制菜单项先例（`railui.page.js:1967`）同构：DyePanel 场景下 menuFoot 项=颜色列表，非 FSORTS 七键。
3. **选色状态**：`st.fsort` 存 `"pig:<colorId>"`（五键持久化体系照常记）。

### 5.3 JS：专属排序应用（v14.1 同构）

`dispApplyDyePig(D, model)`（`dispApplyBrewSat` 镜像）：
1. `dispRows` join（物品 id 直配，现体系）取 `cfgId` → 查 `ICFG[cfgId].pig` 解析得该色点数
2. 排序：点数降序；null/0（无该色素、非植物）沉底保持原相对序；并列稳定
3. `dispPack` 装填（cols×(rows+8) 余量现规则）→ 写模型 x/y → 官方自渲染
4. 角标：makeBadgeLayer 右上角显所排色点数（`FBCOLOR` 按色号映射该色 hex）；`official` 复位走 dispRestore

### 5.4 行为细节（已与作者对齐）

- **触发**：弹窗选色即排一次；不跟随「提取颜色」联动
- **重应用**：官方推包/换页签（背包↔柜子）后照现体系重应用（DISP 既有 reapply 链）
- **关面板**：状态留存（五键持久化），真实布局从未被改过——无需"还原"动作
- **已解锁色**：官方描边/水滴点数照常自显（官方逻辑不动）；mod 角标与之并存（位置/口径不同，互不干扰）
- **未解锁色**：可排序可看角标，仅"提取"不可（游戏规则）；弹窗不特殊置灰
- **配置**：不新增 cfg 键（排序钮随 DyePanel 页装配；`Access.EnableDye` 管的是柜子页签，与排序钮互不牵连——若作者要独立开关，加 `Access.EnableDyeSort` 一行的事，默认 true）
