# CabinetEverywhere 储物侧栏 UI 规格（UI-SPEC）

> 本文件是储物侧栏 UI 的**唯一定义源**：几何、交互、持久化、场景覆盖都以本文为准。
> 可交互原型与本文同步维护（见 §8 资产与构建）；改 UI 先改原型验证，再改本文，最后动源码。
> 定稿日期：2026-10-30，当前版 **v12**（整理柜自研双面板 + 官方五按钮转移列）；
> 演进史见 §6。上游总设计见同目录 `DESIGN.md`；红线见 `suite\docs\03-教训与红线.md`。

## 1. 定位与形态

每个含储物容器交互的官方界面（烹饪/老鼠笼/酿酒桶/颜料桶/食物压制机/工作台/粉碎机/
温室/无人机交易/调度机队/单独背包/整理柜），其官方背包面板列替换为**固定侧栏**
（storage rail）：柜子、背包、搜索、筛选、排序全部收进这一条 428px 侧栏，
**界面其余部分不改动**。侧栏是页面的一部分（跟随官方 createViewportFit 缩放）；
若要求侧栏永不缩放，实现时挂到缩放容器外层（实现期决定项）。

两个特例形态（v9-v12 定版）：
- **B 键单独背包** = 纯背包页（bagonly）：无柜子页签栏/全库切换，就是单个背包。
- **整理柜** = **自研双面板**（`.sr-duo` 三段一体）：官方原版双面板整体移除，
  换成 左·优化版背包面板 + 中·官方五按钮转移列 + 右·柜子侧栏（详见 §4.5），
  整理=背包↔柜子互转，两侧全程同屏。

## 2. 几何（全部锁定，任何容器/柜子/操作都不改变页面尺寸）

| 项 | 值 | 说明 |
|---|---|---|
| 画布 | 1536×864 恒定 | 与游戏 1:1；`box-sizing/margin/padding/zoom` 全部 `!important` 锁死 |
| 侧栏 | 428×816 恒定 | 宽高 min/max/flex-basis 全锁，`align-items:stretch`（防外壳类 center 溢出） |
| 网格 | **10 列 × 34px，间距 6** | 10×34 + 9×6 = 394px 铺满；容量→行数 `rows = ceil(格数/10)`，纵向滚动 |
| 列数调整 | 改 `COLS/SLOT` 两常量 | 40px→8 列、39px→9、34px→10、30px→11；<32px 角标不可读，不建议 |
| 页内容适配 | 复刻官方 createViewportFit | 仅天然超大的页面（无人机交易 ≈86.7%）整页等比缩，恒定不抖 |

## 3. 侧栏结构（自上而下）

1. **头部**：容器名（大字）+ 副标（`10 列 · N 格 · 标签`）。
2. **柜子页签栏**：`背包`（固定首位，右侧 2px 竖线分隔，不可拖拽）+ 常用柜页签
   （可拖拽排序）+ `▾` 按钮。**页签名完整显示不省略、恒一行**：页签按内容自适应宽，
   放不下整行**横向滚动**（滚动条隐藏，物品区高度不受影响）。**选中页签右侧显示
   `✎` 编辑按钮**（方案 2 定稿；未选中不显示），双击页签/菜单行是保留的隐藏快捷方式。
   **B 键单独背包场景整行不显示（bagonly 纯背包模式）；整理柜场景无 `背包` 页签
   （背包=页面左侧背包面板，见 §4.5）**。
3. **搜索行**：搜索框 + `本柜/全库` 范围切换（bagonly 下不显示）。
4. **快捷标签行**：`全部` + 快捷标签 chips（每 chip 自带 ×，点击 chip=切换筛选，
   点 ×=移出快捷栏）+ `＋`。**最多两行**（57px），超出再添加 → toast
   「快捷标签最多两行，请先移除一个」并拒绝。
5. **工具行**：`⇅ 排序` 自定义下拉 + `↓/↑` 方向按钮 + `网格/列表` 分段。
6. **物品区**：网格（当前柜）或列表（强制于全库模式）。**列表 = 同名汇总行**：
   一行一种物品，数量=各叠合计，副行走 `分类 · N 叠 · 最短保质 · 来源`，排序键
   按汇总值计（交易价值=Σ单价×数量）。
7. **悬停详情条**（列表行附 `右键取 1 · Shift+右键整行` 口径提示）+ **页脚**：
   左 `已用/总格数 · N 行`，右**动作组**（v11 起在底部，对齐官方「整理在面板下方」
   的习惯）：`一键整理`（任意容器，官方 action-btn 同图标；全库视图隐藏）+
   `📦 一键入库`（背包页专属，见 §4.6）。

## 4. 交互规格

### 4.1 容器（▾ 菜单）
- `▾` 打开 **196px 小号悬浮菜单**：分组（食品类/材料类/功能类/自定义标签/未打标签）
  + 纯名称行；无搜索、无格子数、无底栏。
- 菜单行**单击=切换容器（菜单保持打开，高亮原地更新）**；点空白处/Esc 关闭。
- **双击页签或菜单行 = 打开容器设置弹窗**（隐藏快捷方式）。

### 4.2 容器设置弹窗（✎ 主入口 / 双击快捷）
- 248px 小窗：名称输入（≤8 字）+ 官方 26 标签分组多选（+自定义词表组）+ 取消/保存。
- 保存即生效：标题/页签/菜单分组/全库标签过滤全部同步；持久化见 §6。
- ✎ 按钮属性：`draggable=false` + mousedown stopPropagation（不与拖拽冲突）；
  点击不触发容器切换。

### 4.3 排序（6 项定稿）
交易价值 / 保质期 / 饱食度 / 生命 / 精力 / 心态。默认 `↓` = 数值高在前，
方向按钮切换 `↑`。**交易价值 = 单价 × 数量（总数计）**；其余为单体属性。

### 4.4 标签与搜索范围
- 标签 chips 筛的是**物品**，不是柜子：柜子维度的选择由页签/▾ 菜单负责（先选柜，
  再筛物）；柜子标签只参与下面两条路径。
- 默认**本柜**：按物品分类过滤**当前柜子里的物品**（不切柜、不藏页签）。
- `全库`：搜索+标签跨全部容器过滤物品；命中 = 物品分类带该标签 **或** 来源容器
  带该标签（柜子标签在此参与）；列表显示来源容器（汇总行显示首个来源 + `等 N 处`）；
  自动锁列表模式（前 300 条）。
- 柜子标签的第三用途 = 一键入库路由（§4.7）。

### 4.5 场景入口默认容器与侧栏构成（v8；v9-v12 定版）
进入场景落到「该界面官方原面板展示的那一侧」：
- **B 键单独背包 = 纯背包页**（bagonly：柜子页签栏与全库切换一律不显示，页面就是
  单个背包；一键入库照常可用，后台按标签入柜）。
- **整理柜 = 自研双面板 + 中间官方转移列（v11/v12）**：官方 rack-system 原版双面板
  **整体移除**，注入 `.sr-duo` 三段一体 = 左**优化版背包面板**（自研：头部/网格/
  悬停/底部动作组，右键物品 = 放入右侧当前柜 1 件、Shift+右键整堆）+
  **中间转移按钮列**（**官方改版背包 BackpackUI 双背包同款五按钮，标记照搬官方
  静态模板、按钮样式用页面自带官方 .transfer-btn，不自绘**：`◀全部取出` /
  `◀分类取出`（下拉选分类）/ `放入▶` / `分类放入▶`（下拉）/ `按标签放入▶`
  （按右侧当前柜的**标签规则**放入，按钮上方显示标签色点，随切柜联动更新；
  柜子无标签 → toast 拒绝）。整叠批量互转，满则整叠跳过计数）+
  右**柜子侧栏**（纯柜子页，无背包页签，右键取出）。转移后三段联动。
- 其余机器界面（官方被替换的原面板就是背包）→ 背包页，柜子页签正常显示。
原型切场景时重置到该默认。

### 4.6 底部动作组（v11 定版位置：页脚；整理 + 入库）
- **一键整理**（任意容器）：同名叠合并 + 按 `食材/菜品/材料/医疗/饮品/燃料` 分类
  归位，toast `已整理：N 叠合并为 M 叠`。对齐官方背包**底部** action-btn（同位同
  图标——v9 曾放头部，v11 按官方习惯移回底部）。全库视图隐藏（对象不明）。
- **📦 一键入库**（背包页专属）：点击**先弹确认窗**（`背包现有 X 件（Y 叠），将按
  物品分类放入带对应标签的柜子…`，取消/确认入库，弹窗锚在底部按钮上方），确认后
  才执行 §4.7 的分配；背包为空直接 toast 不弹窗。**入库按钮加入 document 级弹层
  关闭监听的豁免清单**（否则同一次点击冒泡会把刚打开的弹窗立刻关掉——v9 实测踩坑）。
  整理柜场景该按钮在**左侧背包面板**底部（主侧栏隐藏）。
- **整理柜互转（v11）**：左侧背包面板物品 右键=放入右侧当前柜 1 件、Shift+右键=
  整堆（与右侧柜子"右键取 1/Shift 整堆"对称）；柜满 toast 拒绝；未选柜（不会发生，
  默认大型置物架 A）兜底提示。

### 4.7 一键入库分配规则（v8 定版，v9 加确认前置）
- 背包物品**按物品分类（食材/菜品/材料/医疗/饮品/燃料）匹配柜子标签**，按页签
  顺序优先（常用柜在前）放入；柜满顺延下一个同标签柜；无匹配/全满的留在背包。
- 完成后 toast 汇总 `已入库 N 件 → 柜名×n …（M 件留背包）`。

### 4.8 取出：右键口径（v8，网格/列表一致）
- **右键 = 取 1 件入背包；Shift+右键 = 整堆（列表行=整行全部）**。与官方口径
  一致：webui-bag 右键=快转一件；官方汇总行组件 webui-rackrows 注释原话
  「右键 = 快速转走一件（口径同背包面板右键快转）」，整行取出官方走专门按钮。
- 取出物并入背包同类叠（不占新格）；无同类叠且背包满 → toast「背包已满」中止。
- 背包自身的格/行右键 → toast「已经在背包里了」。物品区空白处右键不弹浏览器菜单。
- 悬停详情条常驻提示右键口径。

### 4.9 分场景记忆（localStorage，key 带场景）
| 数据 | key | 粒度 |
|---|---|---|
| 页签拖拽顺序 | `srp_pin_order_<scene>` | 每场景（背包不存，恒首位） |
| 快捷标签 | `srp_common_tags_<scene>` | 每场景 |
| 容器改名 | `srp_ctn_names` | 全局（跟容器走） |
| 容器标签 | `srp_ctn_tags` | 全局（跟容器走） |
| 自定义标签词表 | `srp_custom_tags` | 全局（词表），快捷栏引用按场景 |

### 4.10 工程教训（实现必须遵守）
- 页签/菜单**原地更新（结构未变不重建 innerHTML）**：否则真实双击因节点被替换而
  派发到公共祖先失效；单击+重建也会让第二次点击落空。
- 弹层开关顺序：**先切 hidden 再渲染内容**（渲染函数有 hidden 早退守卫）。
- 官方 v-if 浮层要 `hidden` + `#srp .gpage [hidden]{display:none !important}`；
  注入格子容器必须内联 `display:grid` 样式（官方由 JS 设置，静态会塌陷/堆叠）。
- 验证必须用真实输入事件（Playwright click/dblclick），合成 dispatchEvent 测不出
  dblclick 合成逻辑类 bug。
- **官方已有控件一律照搬，禁止自绘**（v12 三连修教训）：标记抄官方静态模板、
  按钮样式用页面自带官方 CSS；官方把某些样式类放在别的页面（如转移列的下拉/
  putin 类在 BackpackUI）时，按官方 CSS **原样**搬入，不重新设计。
- **自开弹窗的按钮必须加进 document 级弹层关闭监听的豁免清单**：否则同一次
  click 冒泡到 document 会把刚打开的弹窗立刻关掉（v9 入库确认弹窗实测踩坑）。
- **多面板场景联动刷新**：主侧栏任何渲染（切柜/切视图/转移）都连带刷新背包面板，
  否则「按标签放入」色点会滞留旧柜子标签（v12 实测踩坑）。
- 验证时**别读隐藏元素的旧 DOM**：列表模式下网格是 hidden 的旧快照，读它会得出
  假数据（v8 排障实录）；页面若可滚动，截图前先 scrollTo(0,0)。

  标记抄官方静态模板、按钮样式用页面自带官方 .transfer-btn，仅 BackpackUI 侧独有
  样式（下拉/putin）按官方 CSS 原样补入 rail.css。整叠批量互转+按分类/按标签批量
  互转，满则跳过计数；下拉点外/Esc 收起；主侧栏任何渲染连带刷新背包面板（色点
  跟随切柜）。实测：分类放入 68 件（食材）、分类取出 292 件（菜品）、按标签放入
  16 件（材料·零件）/15 件（医疗，切柜后语义跟随）、全部取出 1505 件清柜。
