## 0a. v13.4 BackpackUI 原生模式（作者 2026-10-31 执行令落地）

**B 键单独背包 / 开柜双背包（整理物资）两形态：官方页整页原生，mod 零 DOM 改造**，
仅向该页 iframe 文档注入 `style#srNativeBp`（ensureNativeBp，幂等，重载重注）：

1. **格区高度滚动**：`.grid-container{max-height:560px;overflow-y:auto;
   scrollbar-gutter:stable;…}`；官方 JS 写死 inline `width:cols*56px`+全页 border-box，
   滚动槽会从官方宽度里扣 → 格底 `repeat(cols,56px)` 轨道与 px 物品层被顶进滚动条底下。
   **修正= `box-sizing:content-box;padding-right:12px`**（滚动槽加在官方宽度之外；
   原型实证：格底完整 cols×56、物品↔滚动条间隙≥2px）。
2. **柜侧隐负重条**：`.bag-panel.is-storage .weight-section{display:none}`（官方源码：
   dual 且 side==='B' 才挂 is-storage）——背包侧负重照常，柜侧隐藏；B 键单背包无
   is-storage=负重照常。
3. **列数=官方数据原生**（Config_Bag：背包 12~15 列、柜 10~20 列）。**作者 2026-10-31
   拍板：柜宽统一 12 列**（v13.8）——实现走数据层改写（A 重启用 CabinetSize 档位 /
   B 内建 SizeEngine，途径=实现期选择项，目标恒 12）；不做任何视图层伪列（防幻影格
   落点错乱）。原型三 live 场景 mock 12 列、机器侧栏 12×34px，两线一致。
4. **背包面板 mod 按钮对（v13.9，作者缺陷单#1，原型三轮定稿 2026-10-31）**：官方
   `.toolbar` 按钮行（一键丢弃/一键整理所在行）**行首左缘**插入两钮（`margin-right:auto`
   吃余空间=mod 对钉左缘、官方两钮保持右缘，同排两端）——基类=官方 `.action-btn`
   （§4.10「mod 新增按钮用页面自带官方类」，金色点缀 v13.7/v13.6 同款）：
   - **`⇅ 排序 ▾`**：FSORTS 7 项弹层（v13.7 参考图样式，挂触发钮内 absolute 上弹）；
     选中=**显示层重排**（v1.8.5 DISP：改页面模型 x/y 自渲染，真实摆放零触碰，§4.11
     同管线）；属性排序时背包格右上角**数值角标**
     （v1.8.5 同款壳层 overlay，`.srn-badges` 挂官方 `.grid-container` 内、pointer-events:none、
     MutationObserver 跟随官方重渲染，同串免写防回环；webui-bag `.item id=logicId`
     精确匹配，宁缺勿错）。
   - **`📦 一键入库`**：§4.6/§4.7 全流程（空背包 toast 不弹窗；确认窗锚按钮上方；
     `storeAll{order}` 差量汇总 toast 走 toast() 兜底路由到本页自持 `#srnToast`）。
   - **装配判据（v13.10 改页面 Vue 真源）**：`setupState.bagA/bagB.ownerId`——单面板
     A 命中契约白名单=取用柜（柜侧），否则（背包实体/后备箱等）=袋侧；兜底链=DOM chips
     （取用柜 canTag 挂 chips）→ ctx.bpBag → 保守袋侧。**旧判据 ctx.bpBag 是上一包
     快照**：开取用柜瞬间滞后=true → 袋侧按钮对先装上柜面板、下一包推到即摘=「左下角
     排序钮闪一下就没了」（v1.8.4 起固有竞态）——真源判当场可判（官方 ready 门保证
     面板出现时 ownerId 已绑定），竞态根治。官方元素零 addEventListener（监听只在
     mod 自有钮/弹层；文档级「点空白收弹层」含 mod 钮豁免=v9 同款）；弹层 `[hidden]`
     必须 `!important` 压过 ID display 规则（v13.9 实测「按钮上方常驻黑条」教训，§4.10 同源）。

## 0a-5. v13.10 柜侧排序（取用/整理物资，作者 2026-11-03 令）

**所有储物柜（'c' 柜子+'f' 冰箱；材料架 'r' 行组件页不做）的取用与整理物资界面，
柜侧面板官方 `.toolbar` 行首左缘装配 `⇅ 排序 ▾`（仅排序，无入库——入库语义只对背包
成立）**，与袋侧同款 FSORTS 7 项弹层/显示层排序/数值角标（`.srn-badges` 同规）：

- **取用（单柜面板）**：柜面板=袋侧钮对即摘、柜侧排序钮（`srnSortBtn2`，单钮
  `.srn-only` 自钉左缘）在位；排序对象=该柜模型（bagA，ownerId=柜）。
- **整理物资（双背包）**：A 面板袋侧双钮（id 沿用）+ B 面板 `.is-storage` 柜侧仅排序钮；
  **DISP 双实例（DISP/DISP_CT）两侧独立排序互不顶替**（袋按饱腹、柜按保质期同时成立），
  拖拽 dropFilter 按落点 owner 双实例取命中者。
- **进页沿重置双侧同沿**（换页/换文档：fsort/DISP 双实例全复位）；同页形态翻转
  （取用↔整理）=切柜续排口径（排序态保留，模型数组换新自动重抹）。
- **同节点复用双防线**（solo↔取用翻转 Vue 原地复用同一面板）：观察器 marker 按侧别
  （`__srnMO`/`__srnMO2`，防后到侧挂不上）；观察器回调现验「本侧面板在场」（防旧侧
  观察器把对侧刚写的显示层排序 dispRestore 回滚）。

随本页 rail 一并不在 BackpackUI 出现的：~~排序/一键入库~~（v13.9 起以 §0a-4 按钮对
回归）/跨柜页签/搜索/标签。rackOpen/forge/官方 SORT 刷新机关无 rail 自休眠。验收
矩阵：本页按「官方页原生 + srNativeBp 在场 + 滚动条不压格 + 柜侧无负重条 + 按钮对
在场且官方动作逐项不受扰」执行（§7）。

## 0. 动作保真红线（总纲，2026-10-31 作者总裁决）

**本 mod 的职责 = 重构储物系统的布局与导航（壳），不重造储物系统（物品格）。**
所有版本的硬约束，验收一票否决项：

1. **物品格/行组件 = 官方 DOM 原件**（reparent 搬进壳允许；自绘、复刻、代理监听一律禁止）。
   对官方元素**零 addEventListener**（display 层过滤除外）。
2. **官方动作原生存活**，逐项清单：
   左键详情 / 拖拽移动（格↔格、格↔机器槽、行↔背包）/ 右键快转一件 / 高亮键批转 /
   使用 / 丢弃 / 入机器槽 / 整理柜行组件锁定行、取出最多、落点预览 / 机器人存入开关。
3. **mod 自有交互仅限三类**：①壳 chrome（页签/搜索/标签/排序/列表/弹窗）；
   ②新增整柜批量动作（一键整理/一键入库/分类与按标签互转，C# 官方 API 直调）；
   ③rackOpen（整理柜跨柜 = C# 重放官方 `Ac_MaterialRack_Open` 动作，官方 state 整体重绑，
   官方行组件原生重渲染——非伪造、非自绘）。
4. **列表行事件分两代**（v1.9.0 修订，作者 2026-11-07 裁决「没有推翻，他们是一起的」）：
   v1.8.x 全库列表（`.sr-row`）=纯汇总只读、行零事件（取出/放入回官方网格做）——照旧；
   **v1.9.0 glist 全局物品栏行（`.srg-row`）=汇总显示+右键官方事件回放一体**：悬停/左键
   =只读（信息条/详情），右键=官方口径移 1 件（暖炉 feed 官方动作、染料页面官方
   ITEM_CLICK{rightClick} 回放——Unity 裁决+官方飘字，mod 不拦截不伪造），见 §0b-glist。
5. **验收 = §7 动作矩阵逐项实机打勾**；床测全绿不替代实机，缺一项不交付。
6. 修订历史条款：「官方原版背包禁绝」（v11）限缩为**禁整页原版 chrome**——物品格
   一律官方原件（本条为 v13 对 v11/v12「自研面板/自绘格/复刻按钮」三要素的显式推翻）。

## 1. 定位与形态

每个含储物容器交互的官方界面（烹饪/老鼠笼/酿酒桶/颜料桶/食物压制机/工作台/粉碎机/
温室/无人机交易/调度机队/单独背包/整理柜），其官方背包面板列替换为**固定侧栏**
（storage rail）：柜子、背包、搜索、筛选、排序全部收进这一条 428px 侧栏，
**界面其余部分不改动**。侧栏是页面的一部分（跟随官方 createViewportFit 缩放）；
若要求侧栏永不缩放，实现时挂到缩放容器外层（实现期决定项）。

两个特例形态（v13 定版）：
- **B 键单独背包** = 纯背包页（bagonly）：无柜子页签栏/全库切换，就是单个背包；
  物品区 = **官方 .grid-container 原件**搬进壳。
- **整理柜** = **三段壳 + 官方原件**（`.sr-duo`）：官方 `#rackSystem` 原版整体移除，
  左段=官方背包面板原件（`#panelA`：负重条+官方背包格），中段=官方两按钮原件
  （放入材料/全部取出）——**即全部**（mod 三增值按钮 2026-11-07 作者裁决退役，
  见 §4.5），右段=柜子侧栏壳（chrome）+ 官方汇总行面板原件（`#panelB`，含机器人开关），
  详见 §4.5。

### 4.10 工程教训（实现必须遵守）
- 页签/菜单**原地更新（结构未变不重建 innerHTML）**：否则真实双击因节点被替换而
  派发到公共祖先失效；单击+重建也会让第二次点击落空。
- 弹层开关顺序：**先切 hidden 再渲染内容**（渲染函数有 hidden 早退守卫）。
- 官方 v-if 浮层要 `hidden` + `#srp .gpage [hidden]{display:none !important}`；
  注入格子容器必须内联 `display:grid` 样式（官方由 JS 设置，静态会塌陷/堆叠）。
- 验证必须用真实输入事件（Playwright click/dblclick），合成 dispatchEvent 测不出
  dblclick 合成逻辑类 bug。
- **官方已有控件一律用原件（reparent），复制模板仅限 mod 新增按钮的样式**（v12 三连修
  → v13 升格）：v12 的「照搬静态模板」只解决观感，解决不了动作保真——原件才有官方监听；
  mod 新增按钮样式用页面自带官方 CSS 类（.transfer-btn 等），不重新设计。
- **自开弹窗的按钮必须加进 document 级弹层关闭监听的豁免清单**：否则同一次
  click 冒泡到 document 会把刚打开的弹窗立刻关掉（v9 入库确认弹窗实测踩坑）。
- **多面板场景联动刷新**：主侧栏任何渲染（切柜/切视图/转移）都连带刷新背包面板，
  否则「按标签放入」色点会滞留旧柜子标签（v12 实测踩坑；该按钮已随 2026-11-07
  裁决退役，联动刷新原则对残余联动面仍适用）。
- 验证时**别读隐藏元素的旧 DOM**：列表模式下网格是 hidden 的旧快照，读它会得出
  假数据（v8 排障实录）；页面若可滚动，截图前先 scrollTo(0,0)。
