## 0. 动作保真红线（总纲，2026-10-31 作者总裁决）

**本 mod 的职责 = 重构储物系统的布局与导航（壳），不重造储物系统（物品格）。**
所有版本的硬约束，验收一票否决项：

1. **物品格/行组件 = 官方 DOM 原件**（reparent 搬进壳允许；自绘、复刻、代理监听一律禁止）。
   对官方元素**零 addEventListener**（display 层过滤除外）。
2. **官方动作原生存活**，逐项清单：
   左键详情 / 拖拽移动（格↔格、格↔机器槽、行↔背包）/ 右键快转一件 / 高亮键批转 /
   使用 / 丢弃 / 入机器槽 / 整理柜行组件锁定行、取出最多、落点预览 / 机器人存入开关。
3. **mod 自有交互仅限三类**：①壳 chrome（页签/搜索/标签/排序/列表/弹窗）；
   ②新增整柜批量动作（一键整理/一键入库/分类与按标签互转，C# 官方 API 直调）；
   ③rackOpen（整理柜跨柜 = C# 重放官方 `Ac_MaterialRack_Open` 动作，官方 state 整体重绑，
   官方行组件原生重渲染——非伪造、非自绘）。
4. **列表 = 纯汇总只读**：行零事件（无右键取放——取出/放入一律回到官方网格/行组件做）。
5. **验收 = §7 动作矩阵逐项实机打勾**；床测全绿不替代实机，缺一项不交付。
6. 修订历史条款：「官方原版背包禁绝」（v11）限缩为**禁整页原版 chrome**——物品格
   一律官方原件（本条为 v13 对 v11/v12「自研面板/自绘格/复刻按钮」三要素的显式推翻）。

## 1. 定位与形态

每个含储物容器交互的官方界面（烹饪/老鼠笼/酿酒桶/颜料桶/食物压制机/工作台/粉碎机/
温室/无人机交易/调度机队/单独背包/整理柜），其官方背包面板列替换为**固定侧栏**
（storage rail）：柜子、背包、搜索、筛选、排序全部收进这一条 428px 侧栏，
**界面其余部分不改动**。侧栏是页面的一部分（跟随官方 createViewportFit 缩放）；
若要求侧栏永不缩放，实现时挂到缩放容器外层（实现期决定项）。

两个特例形态（v13 定版）：
- **B 键单独背包** = 纯背包页（bagonly）：无柜子页签栏/全库切换，就是单个背包；
  物品区 = **官方 .grid-container 原件**搬进壳。
- **整理柜** = **三段壳 + 官方原件**（`.sr-duo`）：官方 `#rackSystem` 原版整体移除，
  左段=官方背包面板原件（`#panelA`：负重条+官方背包格），中段=官方两按钮原件
  （放入材料/全部取出）+ mod 三增值按钮（分类取出/分类放入/按标签放入），右段=柜子侧栏
  壳（chrome）+ 官方汇总行面板原件（`#panelB`，含机器人开关），详见 §4.5。

## 2. 几何（壳跟随官方原件尺寸；任何容器/柜子/操作都不改变页面尺寸）

| 项 | 值 | 说明 |
|---|---|---|
| 画布 | 1536×864 恒定 | 与游戏 1:1；`box-sizing/margin/padding/zoom` 全部 `!important` 锁死 |
| 侧栏壳 | 高 816 恒定；宽**只增不减锁**（Bug2，2026-10-31） | 首帧按官方格宽锁定（+20px 内边距补偿），遇更宽格才扩、绝不回缩——切柜（袋↔柜/柜↔柜）不挤压变形不闪空白；页面重开自然重置 |
| 柜格宽度 | **统一 12 列**（v13.8 作者拍板，取代 v1.8.2.3 临设 16 列） | 实现走数据层（CabinetSize 档位或逐柜 Width=12，容量差异只增高不增宽）；物品格尺寸跟官方（v1.8.1 缺陷⑥教训），mod 不改格子几何；原型机器侧栏 12×34px 格区、壳宽 494（428-640 区间内），BackpackUI live 场景本就 mock 12 列，两线一致 |
| 网格 | 官方原件 | 格数/尺寸/间距/空格渲染全由官方管线决定；壳只提供滚动容器与显隐 |

## 3. 侧栏结构（自上而下）

1. **头部**：容器名（大字）+ 副标（`10 列 · N 格 · 标签`）。**机器场景（plain）
   不显示头部（v13.6）**——侧栏顶部直接是柜子页签行；容量信息看页脚。
2. **柜子页签栏**：`背包`（固定首位，右侧 2px 竖线分隔，不可拖拽）+ 常用柜页签
   （可拖拽排序）+ `▾` 按钮。**页签名完整显示不省略、恒一行**：页签按内容自适应宽，
   放不下整行**横向滚动**（滚动条隐藏，物品区高度不受影响）。**选中页签右侧显示
   `✎` 编辑按钮**（方案 2 定稿；未选中不显示），双击页签/菜单行是保留的隐藏快捷方式。
   **B 键单独背包场景整行不显示（bagonly 纯背包模式）；整理柜场景无 `背包` 页签
   （背包=页面左侧背包面板，见 §4.5）**。
3. **搜索行**：搜索框 + `本柜/全库` 范围切换（bagonly 下不显示）。
4. **快捷标签行**：`全部` + 快捷标签 chips（每 chip 自带 ×，点击 chip=切换筛选，
   点 ×=移出快捷栏）+ `＋`。**最多两行**（57px），超出再添加 → toast
   「快捷标签最多两行，请先移除一个」并拒绝。
5. **工具行**：`⇅ 排序` 自定义下拉 + `↓/↑` 方向按钮 + `网格/列表` 分段。
   **以上 3-5 行在 9 个机器场景（plain，v13.5）一律不显示**（§4.11）；三 live
   场景（单独背包/取用/整理物资）无 rail，不受影响。交易场景此位置换**买家喜好条**。
6. **物品区**：网格=**官方原件**（当前柜；官方管线渲染，动作全原生）或列表
   （强制于全库模式）。**列表 = 同名汇总行（纯只读，行零事件）**：一行一种物品，
   数量=各叠合计，副行走 `分类 · N 叠 · 最短保质 · 来源`，排序键按汇总值计
   （交易价值=Σ单价×数量）；随机属性物品（timeLeft/flags 任异）不合并、逐叠一行。
   **格子右上角数值角标**（`.s-badge`，v13.5）：仅食品设施属性排序（该维数值）与
   交易场景（计算后交易价值）出现，角标在场时原「新获得」小点让位。
7. **悬停详情条**（网格态提示 `右键快转 · 高亮键批转`=官方原生口径；列表态无动作提示）
   + **页脚**：
   左下角**设施排序按钮**（`⇅ 默认/⇅ 属性名`，仅 5 个食品类设施显示，v13.5），
   中 `已用/总格数 · N 行`，右**动作组**（v11 起在底部；**v13.6 调序：`📦 一键入库`
   在 `一键整理` 左侧**）：`📦 一键入库`（背包页专属，金色，见 §4.6）+
   `一键整理`（任意容器，官方 action-btn 同图标；全库视图隐藏）。

## 4. 交互规格

### 4.1 容器（▾ 菜单）
- `▾` 打开 **196px 小号悬浮菜单**：分组（食品类/材料类/功能类/自定义标签/未打标签）
  + 纯名称行；无搜索、无格子数、无底栏。
- 菜单行**单击=切换容器（菜单保持打开，高亮原地更新）**；点空白处/Esc 关闭。
- **双击页签或菜单行 = 打开容器设置弹窗**（隐藏快捷方式）。

### 4.2 容器设置弹窗（✎ 主入口 / 双击快捷）
- 248px 小窗：名称输入（≤8 字）+ 官方 26 标签分组多选（+自定义词表组）+ 取消/保存。
- 保存即生效：标题/页签/菜单分组/全库标签过滤全部同步；持久化见 §6。
- ✎ 按钮属性：`draggable=false` + mousedown stopPropagation（不与拖拽冲突）；
  点击不触发容器切换。

### 4.3 排序（6 项定稿）
交易价值 / 保质期 / 饱食度 / 生命 / 精力 / 心态。默认 `↓` = 数值高在前，
方向按钮切换 `↑`。**交易价值 = 单价 × 数量（总数计）**；其余为单体属性。
v13.5 起机器场景（plain）无工具行，机器场景排序走 §4.11（设施按钮/交易默认）。

### 4.4 标签与搜索范围
- 标签 chips 筛的是**物品**，不是柜子：柜子维度的选择由页签/▾ 菜单负责（先选柜，
  再筛物）；柜子标签只参与下面两条路径。
- 默认**本柜**：按物品分类过滤**当前柜子里的物品**（不切柜、不藏页签）。
- `全库`：搜索+标签跨全部容器过滤物品；命中 = 物品分类带该标签 **或** 来源容器
  带该标签（柜子标签在此参与）；列表显示来源容器（汇总行显示首个来源 + `等 N 处`）；
  自动锁列表模式（前 300 条）。
- 柜子标签的第三用途 = 一键入库路由（§4.7）。

### 4.10 工程教训（实现必须遵守）
- 页签/菜单**原地更新（结构未变不重建 innerHTML）**：否则真实双击因节点被替换而
  派发到公共祖先失效；单击+重建也会让第二次点击落空。
- 弹层开关顺序：**先切 hidden 再渲染内容**（渲染函数有 hidden 早退守卫）。
- 官方 v-if 浮层要 `hidden` + `#srp .gpage [hidden]{display:none !important}`；
  注入格子容器必须内联 `display:grid` 样式（官方由 JS 设置，静态会塌陷/堆叠）。
- 验证必须用真实输入事件（Playwright click/dblclick），合成 dispatchEvent 测不出
  dblclick 合成逻辑类 bug。
- **官方已有控件一律用原件（reparent），复制模板仅限 mod 新增按钮的样式**（v12 三连修
  → v13 升格）：v12 的「照搬静态模板」只解决观感，解决不了动作保真——原件才有官方监听；
  mod 新增按钮样式用页面自带官方 CSS 类（.transfer-btn 等），不重新设计。
- **自开弹窗的按钮必须加进 document 级弹层关闭监听的豁免清单**：否则同一次
  click 冒泡到 document 会把刚打开的弹窗立刻关掉（v9 入库确认弹窗实测踩坑）。
- **多面板场景联动刷新**：主侧栏任何渲染（切柜/切视图/转移）都连带刷新背包面板，
  否则「按标签放入」色点会滞留旧柜子标签（v12 实测踩坑）。
- 验证时**别读隐藏元素的旧 DOM**：列表模式下网格是 hidden 的旧快照，读它会得出
  假数据（v8 排障实录）；页面若可滚动，截图前先 scrollTo(0,0)。

## 7. 验收清单（每次改 UI 后必须全绿）

1. 12+1 场景：gpage=1536×864、壳高 816、壳宽 max-content 跟官方格（428-640），
   切容器/柜子页面尺寸不变。
2. ✎ 仅选中页签可见，点击开弹窗且不切容器；双击页签/菜单行仍可用。
3. 拖拽排序生效并持久化（分场景）；背包固定首位、不可拖。
4. 标签：启用/× 移除/两行上限 toast；排序 6 项+方向+总价；全库带来源。
5. 容器设置：改名+打标签保存后全处同步、刷新保留。
6. **入口默认与场景构成（v8/v13）**：B 键单独背包=纯背包页（官方 .grid-container
   原件在壳）；整理柜=三段壳+官方原件（左 #panelA 原件 + 中官方两按钮原件+mod 三按钮
   + 右壳 chrome+#panelB 原件）；机器场景默认背包页（官方格原件在壳）。

   （叠合并+分类归位，toast）；一键入库仅背包侧显示且**必经确认弹窗**（整理柜场景
   无入库按钮——背包在左段，放入走官方流程）。
